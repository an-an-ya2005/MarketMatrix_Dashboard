# MarketMatrix_Dashboard

An interactive Power BI / Excel dashboard built using the SuperStore_Sales_Dataset.csv to analyze key business metrics.
The dashboard visualizes sales performance, profit trends, and regional insights through dynamic charts, filters, and KPIs — helping users explore market patterns and make data-driven decisions.
<img width="1324" height="743" alt="image" src="https://github.com/user-attachments/assets/ee359a5b-3300-4cf9-ab96-352b66a5505f" />

Key Features:

Sales and profit analysis by category, sub-category, and region

Geographic visualization using maps (state & city-level insights)

Time-based performance tracking (monthly/quarterly trends)

Interactive filters and slicers for deep data exploration

Dataset: SuperStore_Sales_Dataset.csv
Tools Used: Power BI / Excel (Pivot Charts, PowerPivot, Maps, KPIs)
